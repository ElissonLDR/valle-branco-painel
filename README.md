# Valle Branco — Painel

Dashboard simplificado do wp-admin com atalhos para as principais configurações do site Valle Branco.

## Recursos

- Boas-vindas com cores da marca
- Cards com contagens ao vivo: Artigos/Receitas, Mapa, Banners, Produtos, Usuários
- Card de atualizações do sistema (somente administradores)
- Substitui o Dashboard padrão e o logo do WordPress na barra superior

## Instalação

1. Envie a pasta `valle-branco-painel` para `wp-content/plugins/`
2. Ative o plugin em **Plugins**
3. Acesse **Painel** no menu lateral (ou faça login — redireciona automaticamente)

## Requisitos

- WordPress 6.0+
- PHP 7.4+
